# FinTrack — приложение для управления личными финансами

Современное кроссплатформенное мобильное приложение на React Native и Expo для учёта личных финансов, управления транзакциями и анализа финансового поведения. FinTrack сочетает интуитивный интерфейс в стиле глассморфизма, конвертацию валют в реальном времени и развитую аналитику.

## Обзор

FinTrack — полнофункциональное приложение для управления личными финансами, которое помогает пользователю взять под контроль свои доходы и расходы. Приложение позволяет:

- фиксировать доходы и расходы;
- категоризировать транзакции;
- строить подробные отчёты и диаграммы;
- планировать бюджет в нескольких валютах.

Основной акцент сделан на UX: плавные анимации, поддержка тёмной темы и чистый современный интерфейс.

## Архитектура

### Управление состоянием

Приложение использует React Context API для глобального состояния, разделяя его на три основных контекста:

1. **AuthContext** — состояние пользователя и JWT‑токена, вход/выход
2. **AppContext** — транзакции, категории, выбранная валюта и агрегированная статистика
3. **ThemeContext** — текущая тема (светлая/тёмная/системная) и цвета

### Интеграция с backend

- Используется **RESTful‑клиент** с автоматическим добавлением JWT‑токена в заголовки
- Обработка ошибок инкапсулирована в кастомном классе `ApiError`
- Поддерживается **мок‑режим**: при `USE_MOCK = true` фронтенд работает на локальных данных без реального backend
- Все вызовы типизированы через интерфейсы TypeScript

### Хранение данных

- **AsyncStorage**: локальное хранение настроек пользователя и токена
- **Кэш курсов валют** с TTL 1 час и fallback на жёстко заданные значения
- **Оффлайн‑режим**: при отсутствии сети используются закэшированные данные

### Навигационный поток

```
Welcome → Auth → Verify Code → Dashboard
                 ↓
          Tabs: Dashboard, Transactions, Add, Analytics, Settings
```

## Начало работы

### Требования

- Node.js v18+
- npm или yarn
- Expo CLI (`npm install -g expo-cli`) — либо использование `npx expo`
- iOS Simulator (macOS) или Android Emulator (Android Studio)

### Установка

1. **Клонируйте репозиторий**

   ```bash
   git clone <repository-url>
   cd finance-app-frontend
   ```

2. **Установите зависимости**

   ```bash
   npm install
   # или
   yarn install
   ```

3. **Настройте переменные окружения**

   Создайте файл `.env` в корне проекта:

   ```env
   EXPO_PUBLIC_API_URL=http://localhost:8000/api/v1
   ```

   При необходимости добавьте `EXPO_PUBLIC_USE_MOCK`, чтобы управлять режимом мок‑данных.

4. **Запустите dev‑сервер**

   ```bash
   npm start
   # или
   expo start
   ```

5. **Выберите платформу**

   - Нажмите `i` для iOS‑симулятора
   - Нажмите `a` для Android‑эмулятора
   - Нажмите `w` для web‑версии
   - Либо отсканируйте QR‑код через приложение Expo Go на устройстве

### Полезные скрипты

- `npm start` — запуск Expo dev‑сервера
- `npm run ios` — запуск iOS‑симулятора
- `npm run android` — запуск Android‑эмулятора
- `npm run web` — запуск web‑версии
- `npm run lint` — проверка ESLint
- `npm run test` — запуск unit‑тестов (Jest)

## Docker

Проект включает поддержку Docker как для разработки, так и для продакшн‑сборки web‑версии.

**Разработка (Expo dev server для web):**

```bash
docker compose up frontend
```

Откройте `http://localhost:8081`. Настройте `.env` или задайте `EXPO_PUBLIC_API_URL` и `EXPO_PUBLIC_USE_MOCK` по необходимости.

**Продакшн‑режим (статический web‑export под nginx):**

```bash
docker compose --profile web up frontend-web
```

Откройте `http://localhost:8080`.

**Ручная сборка образов:**

```bash
# Dev‑образ (Expo dev server)
docker build --target dev -t fintrack-frontend:dev .

# Продакшн‑образ (web‑export + nginx)
docker build --target web -t fintrack-frontend:web .
```

## Конфигурация

### API

Фронтенд ожидает FastAPI‑backend с базовым URL:

```env
EXPO_PUBLIC_API_URL=http://localhost:8000/api/v1
```

Этот URL можно переопределять через `.env` для разных окружений (dev, staging, prod).

### Мок‑режим

Переключение режима происходит в `services/api-client.ts`:

```typescript
export const USE_MOCK = true; // false — для реального API
```

В мок‑режиме все запросы к backend подменяются локальными данными из `mock-data.ts`, что позволяет разрабатывать UI независимо от готовности API.

## Пояснения к ключевым функциям

### Поток подтверждения e‑mail

После регистрации или входа пользователь получает 6‑значный код на почту. Экран верификации поддерживает:

- авто‑переключение между полями ввода;
- вставку кода из буфера/авто‑заполнения SMS;
- повторную отправку кода с таймером 60 секунд;
- обработку ошибок для просроченных и неверных кодов.

### Конвертация валют

Бэкенд хранит суммы в USD. Фронтенд:

- запрашивает курсы валют у внешнего API;
- кэширует значения на 1 час;
- использует заранее заданные курсы при оффлайне;
- прозрачно конвертирует суммы в выбранную пользователем валюту.

### Глассморфизм

UI строится вокруг "стеклянных" карточек:

- полупрозрачные фоны с blur‑эффектом;
- аккуратные бордеры и тени;
- градиентные подложки;
- плавные анимации появления/изменения.

### Аналитика

Экран аналитики предоставляет:

- столбчатые графики динамики доходов/расходов;
- круговые диаграммы распределения расходов по категориям;
- фильтрацию по периоду (месяц/квартал/год);
- визуальное представление ключевых метрик.

## Интеграция с backend

Фронтенд ожидает FastAPI‑backend со следующими основными эндпоинтами:

- `POST /auth/signup` — регистрация
- `POST /auth/login` — вход
- `POST /auth/verify-code` — подтверждение кода
- `POST /auth/resend-code` — повторная отправка кода
- `POST /auth/social` — социальная аутентификация
- `GET /auth/me` — текущий пользователь
- `POST /auth/logout` — выход
- `GET /transactions` — список транзакций
- `POST /transactions` — создание транзакции
- `GET /transactions/:id` — получение транзакции
- `PATCH /transactions/:id` — обновление
- `DELETE /transactions/:id` — удаление
- `GET /transactions/stats` — статистика
- `GET /categories` — список категорий
- `POST /categories` — создание категории
- `PATCH /categories/:id` — обновление
- `DELETE /categories/:id` — удаление

Подробное описание API см. в документации backend (`BACKEND_HANDOFF.md` и Swagger‑UI).
