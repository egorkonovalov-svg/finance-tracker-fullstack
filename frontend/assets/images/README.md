# App images

Placeholder PNGs are present so the project builds. For production, replace with:

- **icon.png** – App icon (recommended 1024×1024)
- **favicon.png** – Web favicon
- **splash-icon.png** – Splash screen image (referenced in app.json with imageWidth 200)
- **android-icon-foreground.png**, **android-icon-background.png**, **android-icon-monochrome.png** – Android adaptive icon layers

Use [appicon.co](https://www.appicon.co/) or similar to generate from a single 1024×1024 source.
